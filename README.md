## Featured projects

### [LFP Cell Characterisation & 2-RC Model](https://github.com/wolfandbear/Li-ion-batt-cell-model)
Characterised a ~89 Ah LiFePO₄ cell from lab data, identified a second-order equivalent-circuit
model by nonlinear least squares, and validated it on an unseen dynamic profile
(**14.8 mV MAE**). Also covers where the model breaks down at high current.
`Python` `SciPy` `pandas` `battery algorithms`

### [Reinforcement Learning + Neural Network from Scratch](https://github.com/wolfandbear/RobotLearningCode)
A Robocode tank that learns to win with Q-learning, using a backpropagation network written from
scratch in Java as the Q-function. Removing state quantisation raised the win rate from ~45% to a
**92% peak**.
`Java` `Q-learning` `backpropagation`
